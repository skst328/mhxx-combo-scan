# MHXX 調合スキャン

Switch 2 で録画した MHXX の調合動画から、ゲーム内の乱数位置（フレーム）を割り出すブラウザアプリです。

調合の様子を録画して読み込ませると、画面に出ている素材と完成品の個数をコマごとに読み取り、
生産数の並びから調合開始時のフレーム位置を特定します。

swtichで録画した動画から調合数の変化を目視で打ち込むのが個人的にしんどかったので自動化ツールを自作しました。

以下のURLから実行できます。

**公開ページ**: <https://skst328.github.io/mhxx-combo-scan/>

## 動画は外に出ません

- 読み込んだ動画が、**インターネット上のどこかに送られることはありません**
- 解析はすべて、**あなたのパソコンやスマホの中**で行われます
- 動画も解析結果も、**どこにも保存されません**

ページを開くときにプログラムを受け取るだけで、そのあとは通信しません。
動画を選んだあとは、インターネットに繋がっていなくても動きます。

## 使い方

1. **調合を録画する** — 素材を 99 個持った状態から、完成品が 99 個になるまで、
   **ボタンを押しっぱなしにして**連続で調合する
2. **動画を手元の端末に移す**（下記参照）
3. アプリを開いて、**動画をドラッグ&ドロップ**（スマホならタップして選択）
4. 必要なら解析範囲と探索範囲を変える（初期値のままで大抵は足ります）
5. **解析する** を押す

しばらくすると、調合開始時のフレーム位置と、調合 1 回ごとの生産数の明細が出ます。

解析に時間がかかる場合は、**解析する動画時間の範囲を調合している部分だけに絞る**と短くなります。
動画全体を読むと、調合していない部分にも同じだけ時間がかかります。

### 動画の移し方

**Nintendo Switch App でスマホに送る方法で動作を確認しています。** この経路なら
1280×720 のまま保たれます。

USB 接続や microSD カードで直接パソコンに移す方法は試していませんが、
元のファイルがそのままコピーされるのであれば問題なく動くはずです。

動画を移す方法によっては解像度が変わることがあります。
「1920×1080 の動画です」などと出たら、元のファイルをそのまま移せる方法を探してください。

## 動画の条件

| | |
|---|---|
| 解像度 | **1280×720**（Switch 2 の録画機能そのまま） |
| フレームレート | 30fps |
| レシピ | 素材を 1 回に 1 個ずつ消費し、1 回の生産数が 2〜4 個のもの |
| 調合 | 成功率 100%（失敗すると解析エラーになります） |

条件に合わない動画は、読み込んだ時点で理由が表示されます。

**調合は0 ~ 99個になるまでの区間を含めてください。** 調合回数が少ないと、フレーム位置を一意に絞れないことがあります。

### 検証できている録画方法

**Switch 2 の録画機能で撮ったものだけです。** その動画をそのまま読み込ませて動くことを確認しています。

**Switch 1 の録画機能やキャプチャボード経由の録画は試していません。** 解像度が 1280×720 でも、
映像の圧縮のされ方、拡大縮小の有無、色の扱いが違うと、画面上の数字を読めないことがあります。

動くかもしれませんし、動かないかもしれません。動かないという報告があれば、気まぐれで対応するかもしれません。

## 動作環境

動画のデコードに [WebCodecs](https://developer.mozilla.org/docs/Web/API/WebCodecs_API) を使います。
Chrome、Edge、Safari、Firefox の現行版で動きます。対応していないブラウザでは、
開いた時点でその旨が表示されます。

自分の環境では、PC, Android, iPadOSで動作を確認しています。

## うまくいかないとき

| 症状 | 原因 |
|---|---|
| 「1920×1080 の動画です」と出る | 録画設定かファイルの変換で解像度が変わっています |
| 「調合が見つかりませんでした」 | 調合パネルが映っていないか、レイアウトが違います |
| 「解析できません」の行がある | 調合に失敗した回があるか、数字を読み違えています |
| 候補が複数出る | 調合回数が足りません。より長く調合した動画で撮り直してください |

### 「調合の途中で乱数がずれています」と出たとき

生産数の並びが、乱数列と「途中で何フレームかずれた」形で一致したときに出ます。
ずれをまたがない区間から位置を割り出したうえで、どこで何フレーム分ずれたかを表示します。
ずれが打ち消し合っている場合は、補正は要りません。

「**先頭の 1 回を照合から外しました**」と出ることもあります。こちらはずれではなく、
調合開始直後の 1 回が乱数と噛み合わなかっただけで、残りはすべて一致しています。
**補正は要りません**。

**なぜ調合途中に乱数のずれが起こるのかは分かりません。** 

手元の録画を解析したときに実際にこの現象が起きたため、検出する仕組みを入れました。しかし、
**表示されたずれを考慮して時間を合わせれば本当に目的のフレームに届くのかは、検証していません。**

確実を期すなら、撮り直すことをおすすめします。
